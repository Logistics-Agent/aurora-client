# APPLICATION CONTEXT

Logistics AI Control Tower is one enterprise logistics operating system.
Shipment is the central business object.

## End-to-end story

Customer creates Shipment → Documents → OCR → Compliance → Route → Cost → Negotiation → Tracking → Exception handling → Delivery → Billing/Settlement → Completed.

## UX rules

- shipment-centric
- exception-first
- explainable AI
- human approval for sensitive AI-assisted changes
- realtime honesty

## Staff navigation

Overview
