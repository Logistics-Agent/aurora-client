# CODE STYLE + NAMING

Files: kebab-case.
Components: PascalCase.
Hooks: useSomething.
Queries: useShipmentsQuery.
Mutations: useCreateShipmentMutation.
Services: shipmentService.

Use `@/*` imports.
Use strict TypeScript.
Avoid `any`, `@ts-ignore`, and unexplained lint suppression.
Keep files focused and comments about why, not obvious syntax.
