# Login Earth texture

`earth_atmos_2048.jpg` is the Earth surface texture from the Three.js examples:
https://github.com/mrdoob/three.js/blob/dev/examples/textures/planets/earth_atmos_2048.jpg

Used as a texture on a Three.js sphere, not as a static login illustration.
The logistics routes in the login scene are illustrative, not live tracking data.
